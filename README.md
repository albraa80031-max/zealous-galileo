# Legal Agent - GitHub Integration System

## 📋 نظام إدارة البيانات القانونية مع تكامل GitHub

نظام ذكي لإدارة البيانات القانونية وتزامنها تلقائياً مع GitHub.

### المميزات الرئيسية ✨

- 🔄 **مزامنة تلقائية** مع GitHub
- 📊 **إدارة منظمة** للبيانات القانونية
- 🔐 **أمان عالي** للبيانات الحساسة
- 📱 **واجهة برمجية** سهلة الاستخدام
- 📈 **تقارير مفصلة** وإحصائيات

### البنية الأساسية

```
legal-agent/
├── agents/              # ملفات Agents
├── data/                # البيانات المحفوظة
├── github_sync/         # مزامنة GitHub
├── schemas/             # هيكل البيانات
└── config/              # الإعدادات
```

### الاستخدام السريع

```bash
# تثبيت المتطلبات
pip install -r requirements.txt

# تشغيل العامل القانوني
python -m legal_agent --config config.json

# مزامنة مع GitHub
python -m legal_agent.github_sync --sync
```
